# DarkRelay Web3 Vulnerability Labs

This directory is an official tribute to the research and offensive security work done by **DarkRelay Security Labs**. 

We have ported their open-source `Web3-Vulnerabilities` repository directly into the **[RektAcademy.io](https://rektacademy.io)** infrastructure. These vulnerable smart contracts serve as the foundational training ground for our students to master Web3 exploitation.

## The Modules
These contracts isolate critical vulnerabilities in Solidity. Students must exploit:
- Reentrancy Attacks
- Integer Overflows / Underflows
- Transaction Ordering Dependence (Front-running)
- `tx.origin` Phishing
- Time Dependence & Entropy Illusions
