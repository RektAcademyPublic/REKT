# ZIION OS Download Sources

This directory contains resources for **ZIION (Zero-Knowledge & Infrastructure Intelligence Operating Network)**. 

ZIION is an open-source, pre-configured virtual machine environment designed specifically for blockchain security testing, smart contract auditing, and protocol development. It serves as the primary Web3-native environment in the Rekt Academy Armoury, acting as the Web3 equivalent to Kali Linux.

> [!TIP]
> ZIION comes pre-loaded with over 100+ dependencies, frameworks, and auditing tools (including Foundry, Hardhat, Slither, Mythril, and Echidna), completely removing the headache of setting up a local Web3 development environment from scratch.

## 1. Official Downloads (Virtual Machines)
ZIION is primarily distributed as a pre-compiled `.ova` virtual machine image.

* **Official Website:** [https://www.ziion.org/](https://www.ziion.org/)
* **Direct Download Links:** Available via the official website portal.

## 2. Documentation & Setup
For instructions on how to import the `.ova` file into VMware or VirtualBox, allocate RAM, and access the pre-configured IDEs and tools:

* **Official Docs:** [https://docs.ziion.org/](https://docs.ziion.org/)

## 3. Tool Repositories
While the ZIION OS itself is distributed as an image by Halborn Security, the individual tools integrated within the OS (and any custom Rekt Academy ZIION tooling) are maintained as open-source repositories.

* **Halborn GitHub:** [https://github.com/HalbornSecurity](https://github.com/HalbornSecurity)
