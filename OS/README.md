# OS Architecture & Environments

Welcome to the Operating Systems repository for Rekt Academy. This directory contains the configuration files, VPN integrations, and setup scripts for the three primary offensive distributions used within our ecosystem.

### `/Kali`
**Linux Kali for Web2 hacks.** 
The industry standard distribution for traditional infrastructure penetration testing, network reconnaissance, and Web2 application exploitation.

### `/Linux ZIION`
**The Web3 blockchain hacker distro.**
A specialized, heavily-customized distribution pre-configured with the complete toolchain required for smart contract auditing, EVM exploitation, and decentralized finance (DeFi) hacking.

### `/REKT OS`
**The Ultimate Fusion.**
Our proprietary, custom-built OS that merges the best of both worlds. REKT OS natively integrates the entire Web2 and Web3 toolchains, incorporates advanced AI-Agent assistance directly into the terminal, and features automated, zero-touch VPN connections straight into our cloud-hosted lab environments.
